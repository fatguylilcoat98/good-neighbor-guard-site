🧠 CLASPION

A provider-agnostic execution-governance engine — it sits between an agent's intent and consequential execution, evaluates the action across truth / authority / actor-state / world-state / risk, and returns deterministic ALLOW/BLOCK, fail-closed, with a tamper-evident audit trail.

Active Development
🛡️ VeraCore

An evidence-focused verification engine that treats LLMs as unreliable narrators: deterministic computation where possible, multi-source consensus with enforced source diversity, and a dedicated adversarial challenge that tries to prove the answer wrong — returning a confidence-scored result rather than convincing text.
