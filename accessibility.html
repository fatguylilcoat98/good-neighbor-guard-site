Accessibility

Last updated: 2026 · An ongoing commitment, honestly stated.

Our aim

This site aims to follow sensible, WCAG-oriented accessibility practices so it works well for as many people as possible. As an independent operation, this is a best-effort, continuously-improving commitment rather than a formal certification.

What's in place

  • Semantic HTML and a logical heading structure on each page.
  • A "skip to content" link and visible keyboard focus states.
  • Labelled form fields and descriptive link text.
  • Alt text on meaningful images.
  • Respect for the "reduced motion" system setting (animations are minimized).
  • Responsive layouts that adapt to small screens and larger text.

Known limitations

Some embedded third-party content (e.g. YouTube players) follows those providers' own accessibility support. We continue to test and improve.

Feedback

If you encounter an accessibility barrier on this site, please tell us via the contact page so it can be fixed.
